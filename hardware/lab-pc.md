# Lab PC — референсная машина

Конфиг, на котором гонялись кейсы из этого репо (2026). Не «минимальные требования», а **что реально стояло**, чтобы сравнивать: «у меня слабее / так же / сильнее».

Личные пути, логины и серийники не публикуем.

## Железо

| Компонент | Модель / значение |
|-----------|-------------------|
| CPU | Intel Core **i5-12400F** (6P / 12 threads, Alder Lake) |
| GPU | NVIDIA GeForce **RTX 5060 Ti** |
| RAM | **32 GB** |
| OS | **Windows 11** x64, build **26200** |
| Монитор | **1920×1080 @ 144 Hz** (fullscreen через RetroArch) |
| Накопители | два SSD/HDD раздела ~465 GB + ~894 GB (игры/дампы отдельно от системы) |

### Зачем это важно для эмуляции

- **i5-12400F + MTVU / multi-thread VU** — комфортный запас под PS2 (LRPS2) на 2–3× native; узкое место чаще GPU/апскейл и input-стек, не CPU.
- **RTX 5060 Ti** — Vulkan/D3D у RetroArch/PCSX2 без проблем на 1080p; 3× native (~1080p) для SotC — лёгкая нагрузка.
- **32 GB RAM** — с запасом под Steam + RetroArch + XOutput + браузер; для одного LRPS2 хватило бы и 16 GB.
- **1080p 144 Hz** — viewport/zoom в кейсе 001 подогнан под этот режим; на 1440p/4K цифры `custom_viewport_*` надо пересчитать.

## Периферия ввода

| Устройство | Роль |
|------------|------|
| **Oklick GP-315M** (USB, DInput / Twin Shock–клон) | основной геймпад |
| **XOutput** + **ViGEmBus** | DInput → виртуальный Xbox 360 (XInput) |
| **HidHide** | прячет сырой Oklick, чтобы не было двух падов сразу |

Mode LED: **красный = analog** (играть), зелёный = digital (правый стик = кнопки). Подробнее: [cheatsheets/oklick-gp315m.md](../cheatsheets/oklick-gp315m.md).

## Софт эмуляции (на момент кейса 001)

| Софт | Заметка |
|------|---------|
| **RetroArch** | ~1.22.x (Steam-сборка на машине; для игр часто запуск **мимо Steam**, чтобы не ломал Steam Input) |
| Ядро | **LRPS2** / `pcsx2_libretro.dll` |
| Joypad driver | `xinput` |
| Цель кейса 001 | Shadow of the Colossus (PS2), widescreen 16:9, upscale 3× |

Другие эмуляторы на диске (не разобраны в отдельных кейсах пока): PPSSPP, Dolphin и т.п. — появятся отдельными `cases/NNN-…`, когда будет что зафиксировать.

## Типичный порядок запуска (SotC)

1. Mode на паде → красный  
2. XOutput → Start  
3. HidHide cloak ON  
4. RetroArch **без** Steam Input (или bat из `scripts/`)  
5. In-game: Options → Screen → 16:9  

## Если твоя система другая

| У тебя | На что смотреть |
|--------|------------------|
| Слабее CPU (например старый dual/quad) | снизить upscale, проверить MTVU, EE cycle; input-фиксы те же |
| Другой DInput-клон | тот же стек XOutput+HidHide; оси ловить через Configure / CaptureSteps |
| Родной Xbox / 8BitDo Xbox mode | XOutput часто не нужен; Steam Input всё равно может мешать |
| 1440p / 4K | не копируй viewport из кейса 001 один в один |
| Ноутбук + iGPU | SotC на 2–3× может просесть — это не баг пада |
